O xadrez.live usa Cloudflare Web Analytics para entender visitas ao site de forma agregada: páginas acessadas, referências, localização aproximada, navegador, sistema operacional e métricas de carregamento.

Cloudflare Web Analytics não usa cookies. Os dados servem apenas para entender se o site está sendo visitado e quais páginas são úteis.

O código do site é público, incluindo o trecho de analytics usado nos templates HTML.
