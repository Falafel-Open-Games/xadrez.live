# Redesign references

This folder documents the current visual direction for the xadrez.live redesign sprint.

## North star

Use [`01-north-star-meio-termo.png`](references/01-north-star-meio-termo.png) as the primary reference.

It has the best balance for the site:

- clean archive layout, not a marketing page;
- public training notebook feeling;
- off-white paper surface with subtle texture;
- navy ink, olive green accents, quiet gray borders;
- compact cards and timeline blocks;
- a small amount of hand-drawn chess marginalia.

## Working principles

- The site should feel like a practical public archive built by a person, not a generic AI dashboard.
- Prioritize scanability: sessions, games, chat, transcripts, blunders, and timestamps must remain easy to navigate.
- Use doodles as annotations and emphasis, not decoration everywhere.
- Keep cards compact and purposeful; avoid nested cards and oversized landing-page composition.
- Preserve the chess content as the main subject: video, Lichess embeds, chat, transcripts, games, and training notes.
- Favor the notebook/editorial palette over the previous dark orange/brown look.
